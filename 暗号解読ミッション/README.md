# 暗号解読ミッション

暗号を解読するミッション（1〜4）に取り組む、演習アプリです。
講師PCでサーバーを起動し、受講者はブラウザからアクセスします。

| ミッション | 内容 |
|---|---|
| 1 | シーザー暗号（ひらがな・アルファベット）を、暗号円盤で解読する |
| 2 | 総当たり攻撃で、ずらす数が分からないシーザー暗号を解読する（Pythonのプログラムも書いて実行する） |
| 3 | 換字式暗号を、文字の出現頻度と対応表を手がかりに解読する |
| 4 | ヴィジュネル暗号を、鍵を使って復号・暗号化する（Pythonのプログラムも実行する） |

各ミッションの画面には、指令書（解答の入力欄つき）・ヒント・解読ツールがあります。
解答を送信すると、正解かどうかが表示されます。

## フォルダの中身

| もの | 内容 |
|---|---|
| `App/` | 演習アプリ（Elixir/Phoenix） |
| `mission2.py`〜`mission4.py` | ミッション2〜4の、Pythonの参考コード |

## 起動

初めて使うPCでは、先に[環境構築](../環境構築/README.md)を済ませてください（Erlang・Elixir・Python 3.12の導入と、初回の`mix setup`）。

`App`フォルダの`start_server.bat`をダブルクリックするか、`App`フォルダで次を実行します。

```powershell
mix phx.server
```

既定では、サーバーを起動したPC自身（`http://localhost:4000`）からだけ開けます。
講師PCに受講者のブラウザから接続させる場合は、起動の前に環境変数を設定してください。

```powershell
$env:CODEBREAKING_MISSION_LISTEN = "0.0.0.0"   # 全ネットワークで待ち受ける
mix phx.server
```

`http://<講師PCのIPアドレス>:4000`を受講者に案内します。
標準ユーザーで初めて全ネットワークで待ち受けると、Windowsファイアウォールの許可確認が出て、
管理者の資格情報を求められることがあります。

止めるときは、ターミナルで`Ctrl+C`を2回押します。

# ボール結合ゲーム

数字の書かれたボールを落として、同じ数字どうしをくっつけるゲームです。
物理演算ライブラリ「[Matter.js](https://brm.io/matter-js/)」で、ボールが転がったりぶつかったりする動きを作っています。

## ルール

- マウスを左右に動かして落とす位置を決め、クリックでボールを落とします（スマートフォンなどでは、タッチ）。
- 同じ数字のボールがぶつかると、くっついて2倍の数字のボールになります（1→2→4→…→2048）。
- くっついてできたボールの数字が、スコアに加わります。
- ボールが上まで積み上がると、ゲームオーバーです。

## フォルダの中身

同じゲームを、2つの作り方で用意しています。

| もの | 内容 |
|---|---|
| `index.html` | HTMLファイル1つで動く版 |
| `ReactApp/` | 同じゲームを、React（TypeScript）で作った版 |

## 遊ぶ（`index.html`）

`index.html`をダブルクリックして、ブラウザで開きます。
Matter.jsなどのライブラリをインターネットから読み込むので、インターネットに接続している必要があります。

## 遊ぶ（`ReactApp`）

Node.js（npm）が必要です。`ReactApp`フォルダで、次を実行します。

```powershell
npm install    # 初回だけ（必要なパッケージを入れる）
npm run dev
```

ターミナルに表示されるURL（通常は`http://localhost:5173`）を、ブラウザで開きます。止めるときは、ターミナルで`Ctrl+C`を押します。

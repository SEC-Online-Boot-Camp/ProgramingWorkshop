# 文章生成器

文章から「次に来やすい言葉」を数えて、新しい文章を作る仕組み（N-gram）を、画面で順に体験するアプリです。
生成AIが文章を作るときの考え方を、単純な形で学びます。

画面は、次の順に進みます。

| 区分 | 内容 |
|---|---|
| 📝 入力 | 元になる文章を入れる（サンプルの文章も選べる） |
| ✂️ 分割 | 文章を、言葉（トークン）に区切る |
| 📊 分析 | 言葉の並び（N-gram）が何回出てきたか、どのくらいの確率かを数える |
| 🔮 予測 | 入力した言葉の次に来やすい言葉を、確率の高い順に見る |
| ✨ 生成 | 確率に従って言葉をつないで、新しい文章を作る |

サンプルの文章は、ニュース・掲示板・昔話・技術文・日本国憲法の5種類です（`public/samples/`）。

## 準備

Node.js（npm）が必要です。

## 起動

このフォルダの`run_app.bat`をダブルクリックします。

- 初回は、必要なパッケージを入れる（`npm install`）ので、少し時間がかかります。
- 開発サーバーが別のウィンドウで起動し、ブラウザで`http://localhost:3000`が開きます。
- すでに起動しているときは、ブラウザを開くだけです。

止めるときは、開発サーバーのウィンドウを閉じます。

コマンドで起動する場合は、このフォルダで次を実行します。

```powershell
npm install    # 初回だけ
npm run dev
```

# プログラミング教室

プログラミング教室で使う、演習ごとの教材です。使い方は、それぞれのフォルダのREADMEにあります。

| フォルダ | 内容 | 使うもの |
|---|---|---|
| [PyGameチュートリアル](PyGameチュートリアル/README.md) | PyGameの基本（ウィンドウを開く・キーで動かす） | Python・PyGame |
| [衝突回避ゲーム](衝突回避ゲーム/README.md) | 落ちてくる敵を避けるゲーム | Python・PyGame |
| [Webチャット](Webチャット/README.md) | メッセージの投稿・一覧・編集・削除ができるWebアプリを作る | Python・Flask・SQLite |
| [タスク管理](タスク管理/README.md) | 要件定義・設計のワークシートと、タスク管理のWebアプリを作る | Python・Flask・SQLite |
| [データベースの仕組み](データベースの仕組み/README.md) | SQLでシステムトラブルを解決する演習アプリ | ブラウザ（講師PCでElixirアプリを起動） |
| [暗号解読ミッション](暗号解読ミッション/README.md) | 暗号を解読するミッション（1〜4）の演習アプリ | ブラウザ・Python（講師PCでElixirアプリを起動） |
| [文章生成器](文章生成器/README.md) | N-gramで文章を作る仕組みを体験する | ブラウザ（Node.jsで起動） |
| [ボール結合ゲーム](ボール結合ゲーム/README.md) | 同じ数字のボールをくっつけるゲーム | ブラウザ（HTML版・React版） |
| [画像認識](画像認識/README.md) | カメラの手をAIが見分けるじゃんけん | Scratch（Stretch3）・Teachable Machine |

Elixirアプリ（データベースの仕組み・暗号解読ミッション）を動かす準備は、[環境構築](環境構築/README.md)にまとめています。

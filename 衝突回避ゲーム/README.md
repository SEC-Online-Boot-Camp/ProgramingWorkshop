# 衝突回避ゲーム

上から落ちてくる敵を、左右に動いて避けるゲームです。Python（PyGame）で作っています。
[PyGameチュートリアル](../PyGameチュートリアル/README.md)の続きとして使えます。

- 敵を1つ避ける（画面の下まで落ちる）ごとに、スコアが1点増えます。
- 敵に当たると「Game Over !!!!」と表示され、2秒後にゲームが終わります。

## 準備（初回だけ）

Python 3.12が必要です。PyGameを入れます（PyGameチュートリアルで入れていれば不要です）。

```powershell
py -3.12 -m pip install pygame
```

## 遊ぶ

このフォルダで次を実行します。

```powershell
py -3.12 main.py
```

| 操作 | キー |
|---|---|
| 左に動く | `A`または`←` |
| 右に動く | `D`または`→` |

途中でやめるときは、ウィンドウの「×」で閉じます。

## 変えてみる

`main.py`の最初にある定数を変えると、難しさが変わります。

| 定数 | 意味 |
|---|---|
| `ENEMY_MAX` | 画面に同時に出る敵の最大数 |
| `DELAY` | 敵が出てくる確率（大きいほど、たくさん出てくる） |
